# Kansai — Infographic Website

## About the Project
Kansai is an infographic website design created as an academic project for the Infographics course at the National Institute of Design Andhra Pradesh (NID AP).

The project explores information design, visual storytelling, typography, and visual hierarchy to present information through an engaging digital experience.

## Project Details
- **Project Type:** Infographic Website Design
- **Course:** Infographics
- **Institute:** National Institute of Design Andhra Pradesh
- **Tool:** Figma
